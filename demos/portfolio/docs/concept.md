# Mira Solberg: portfolio

Built with the stagecraft skill from `demos/BRIEFS.md`, brief 2. Mira Solberg is fictional.

**Concept.** An index, not a gallery: the work is a table you can read in ten seconds, and the
craft shows up the moment you touch a row.

**Direction.** Archive, with a Quiet header (name, role, local time) and one serif line for the
statement.

**Signature moment.** The specimen preview: hovering a row summons a code-drawn miniature of that
project's interface that follows the cursor; the LIST / GRID toggle re-lays the same rows with a
FLIP transition. On touch the miniatures sit inline in the grid view.

**Intake defaults.** Portfolio; a developer maintains it; Expressive motion; Archive from the
shortlist. Stack: Astro with the client router (the project number is the shared element into
the case study), GSAP + Flip, Lenis on fine pointers.

**Palette.** Paper `#f4f2ec`, ink `#15161a`, active blue `#2f6bff`. **Type.** Inter Tight
(variable), JetBrains Mono (table, meta), Instrument Serif (one statement).

**Chapters.** Statement, Work (08) index with toggle and previews, About with three principles,
Contact, ending. Case study: Ledger, with a working miniature of the timeline it describes.
